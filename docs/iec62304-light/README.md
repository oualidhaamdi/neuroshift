# IEC 62304 / ISO 14971 — "light" documentation

> [!IMPORTANT]
> **Educational exercise — not regulatory documentation.**
> NeuroShift is research software. It is not a medical device, has no intended
> medical use, and has not been developed under a certified quality management
> system (ISO 13485). These documents show how the project *would* be approached
> under IEC 62304 (medical device software life cycle) and ISO 14971 (risk
> management). They are deliberately short and are not a substitute for the real
> process.

classification, so that classification and risk analysis have something concrete
to refer to.
